# BLOCK BLAST — Retro Arcade Edition
 
เกมวางบล็อก 8×8 ธีมและสไตล์เดียวกับ Ultimate XO (ฟอนต์ Press Start 2P + Chakra Petch, สีนีออน, เอฟเฟกต์เส้นสแกน CRT)
 
## โครงสร้างไฟล์
 
| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | โครงหน้าเกม สกอร์บอร์ด กระดาน ถาดบล็อก และหน้าต่างกติกา/จบเกม |
| `style.css` | สไตล์ Retro Arcade (ใช้โทเคนสีและคอมโพเนนต์ชุดเดียวกับเว็บ XO) |
| `game.js` | ตรรกะเกม: ลากวาง เคลียร์แถว คะแนน คอมโบ High Score |
| `audio.js` | เสียงเอฟเฟกต์ 8-bit สร้างด้วย Web Audio API ไม่ต้องใช้ไฟล์เสียง |
 
## วิธีเล่น
 
- ลากบล็อกจากถาดด้านล่างไปวางบนกระดาน 8×8 (หมุนบล็อกไม่ได้)
- เติมแถวหรือคอลัมน์ให้เต็มเพื่อเคลียร์
- วางครบ 3 ชิ้นจะได้ชุดใหม่
- เกมจบเมื่อบล็อกที่เหลือไม่มีที่วาง
## คะแนน
 
- วางบล็อก: 1 แต้มต่อช่อง
- เคลียร์แถว: `20 × (จำนวนแถว)² × คอมโบ`
- คอมโบเพิ่มทุกครั้งที่เคลียร์ และหลุดเมื่อวางติดกัน 3 ชิ้นโดยไม่เคลียร์
- กระดานว่างทั้งหมด (PERFECT): +300
- คะแนนสูงสุดและสถานะปิดเสียงเก็บไว้ใน `localStorage`
## วิธีรัน
 
เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม
ถ้าจะเผยแพร่ ให้อัปโหลดทั้งโฟลเดอร์ขึ้น Vercel หรือโฮสต์ static ใดก็ได้
